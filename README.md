# طرق مصر | Egypt Roads

قيادة حرة على طرقات القاهرة الحقيقية بالليل — لعبة متصفح ثلاثية الأبعاد (Three.js) من غير سباقات ومن غير تحميل: افتح اللينك وسوق.

**اللعب:** https://faresdief.github.io/egypt-roads/

- **خريطة حقيقية**: الطرق مبنية من بيانات OpenStreetMap الحقيقية — من الزمالك على كوبري 6 أكتوبر لوسط البلد، وطريق الهرم لحد الأهرامات. بيانات الخريطة © OpenStreetMap contributors (ODbL).
- **قيادة حرة بس**: مفيش سباقات ولا مؤقت — روّق وسوق في القاهرة بالليل.
- **عربيات مصرية**: فيرنا وتاكسي وميكروباص وغيرهم، بفلوس بتكسبها من القيادة.
- **بيشتغل على الموبايلات الضعيفة**: مقياس جودة تلقائي (دقة العرض والظلال) بيظبط نفسه حسب جهازك وعدد الإطارات الفعلي.
- **PWA**: ضيفه على الشاشة الرئيسية واشتغل أوفلاين.

## التطوير

```bash
python3 build.py          # أعد بناء index.html من ملفات المصدر
python3 build.py --check  # تأكد إن الملف متزامن
node /path/to/e2e/v48.mjs # اختبارات headless
```

`index.html` هو الصفحة الكاملة اللي بتتقدم على GitHub Pages؛ محتواه (CSS + JS) مولّد من الملفات المصدر — متعدّلوش إيدك، عدّل المصدر وشغّل `build.py`.

الملفات: `physics.js` فيزيكا العربية، `carbody.js`/`carspecs.js` جسم ومواصفات العربيات، `world.js` العالم والإضاءة، `fx.js` مؤثرات، `textures.js` خامات مشتركة، `realmap.js` + `realmap-data.json` خريطة القاهرة الحقيقية، `engine.js` محرك اللعبة والقائمة (نسخة مخصوصة للقيادة الحرة بس)، `quality.js` مقياس الجودة التلقائي.

أدوات مجانية بس: Three.js (CDN)، OpenStreetMap، GitHub Pages.
